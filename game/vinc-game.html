Meet Vinc, the robot built from spare parts.

Vinc was put together on the VINC Lab workbench from leftover bits, and a few parts are still missing. Kids write code to guide Vinc through puzzles, and every class they finish gives Vinc a new part. Each part unlocks the next coding idea.

    Why this character
    
    
    Vinc fits the VINC brand and the way kids learn
    
    
    
      
    The brand, brought to life
    Your logo says "VINC, the sum of parts." Vinc is a robot made of parts, so the mascot is the brand. Every time a child says its name, they say yours.
    
      
    A robot that needs instructions
    Robots only do exactly what they're told, so giving Vinc instructions is the most natural reason to write code. Kids understand that straight away.
    
      
    It links to your real robotics lab
    A physical Vinc (micro:bit or ESP32 on wheels) at the Bengaluru centre runs the same code kids write online. Few kids' coding platforms have a real robot to go with them.
    
      
    Original and safe to grow
    CodeMonkey owns the monkey. A robot of your own can become toys, stickers, T-shirts and certificates without any trademark conflict.
    
    
    
  
    

  
    
    
    Personality
    
    
    Curious and eager, and it gets things wrong sometimes
    
    
    Vinc is never the teacher. The child is the engineer and Vinc is the creation. When code fails, Vinc doesn't call it the child's mistake. It blames Glitch, a tiny bug hiding in the code, and the two of them go looking for it together.
    
    
    
      
    
        
    VoiceShort, excited sentences. Uses "we" a lot. Never sarcastic.
    
        
    QuirkSays "Beep-ah!" when surprised. Its antenna bulb blinks when it's thinking.
    
        
    FlawToo literal. If you tell it to step 3 times, it steps 3 times, even into a wall.
    
        
    SidekickGlitch, a cheeky little beetle that hides in broken code. Kids learn that debugging means catching Glitch.
    
        
    DreamTo build a rocket from the parts it collects, which leads into the final AI world.
    
      
    
      
    
        
    Level start"There's a spark up there! Can we reach it in 10 blocks or fewer?"
    
        
    Code fails"Beep-ah! I bumped into a crate on line 3. I think Glitch got into our code!"
    
        
    Three stars"Whoa, that's the shortest code ever! You're a real engineer."
    
        
    New part"Spring legs?! Now I can jump. Let's try repeating that!"
    
      
    
    
    
  
    

  
    
    
    Curriculum · Classes 3 to 8
    
    
    At least 15 activities in every class
    
    
    Each class is one world with one coding idea and one part to win. Classes 3 and 4 are playable in the workshop above. Classes 5 to 8 are designed and ready to build on the platform.
    
    
    
    
    
    
    
    
    Code style by class: Classes 3–4: drag-and-drop blocks→Class 5: blocks with a "show as Python" toggle→Classes 6–8: Python, with the same Vinc and the same worlds
    
  
    

  
    
    
    The game loop
    
    
    What keeps kids coming back
    
    
    
      
    Stars for short code
    1–3 stars per level, based on how few blocks the program uses. Kids replay levels to beat their own score, which quietly teaches them to write efficient code.
    
      
    Sparks to spend
    Stars turn into sparks, which buy paint jobs and hats in the Garage. Kids express themselves without paying with real money.
    
      
    Catch Glitch
    Debug levels start with broken code. Kids find the line where Glitch is hiding and fix it. Debugging becomes a hunt rather than a failure.
    
      
    Class leagues
    Teachers see a class dashboard. Students earn badges and join weekly "Spark Cup" challenges. Rankings stay friendly: first names only, and only within the class.
    
      
    Build-a-level
    After Class 4, kids design their own puzzles and share them with classmates. Making levels for others is the best test of understanding.
    
      
    Real Vinc day
    At the end of each class, run your code on the physical Vinc robot at the centre. Online learning leads into the hands-on lab.
    
    
    
  
    

  
    
    
    If you want options
    
    
    Other names and characters considered
    
    
    
      
    Jodu
    From jod (जोड़), Hindi for "joining" and "a sum". A clever echo of the tagline, but a second name to build and protect alongside VINC.
    
      
    Yantu
    From yantra (यन्त्र), "machine". Short and warm, with a clear Indian root, but no link to the VINC brand.
    
      
    Partu
    "Parts" with a friendly Indian nickname ending, like Bittu or Chintu. Kids get it instantly, but it's a little silly for Classes 7 and 8.
    
      
    Kitbo
    "Kit" + "robot". Rejected: it is too close to KIBO and KUBO, two coding robots that already sell to schools.
    
      
    Tara the Firefly
    A different character: lights up paths in night levels. It's harder to link to robotics, and "giving instructions" makes less sense for an insect.
    
    
    
    
    The robot is named Vinc, after the company. VINC DEEPTECH has applied for the VINC trademark in class 9 (software). The mascot will also appear on the online platform, a physical robot and merchandise, which fall in other classes.
